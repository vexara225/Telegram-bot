## Celestia - Telegram-бот для игроков Genshin Impact
Celestia - Telegram-бот, созданный для игроков Genshin Impact, которые хотят найти новых друзей, познакомиться с другими путешественниками и найти напарников для совместной игры

### Возможности:
- Создание и редактирование анкеты игрока
- Поиск других игроков
- Модерация пользовательских анкет (для администрации)
- Указание игровой информации: никнейм, возраст, регион сервера, уровень приключений и информация о себе

### Используемые технологии:
- Python
- pyTelegramBotAPI (TeleBot)
- SQLite
